# 设备Logic层流程图

## 概述

本文档描述了OneGoServer项目中设备Logic层的主要业务流程和数据处理流程。

## 1. 设备配置管理流程

```mermaid
flowchart TD
    A[开始] --> B[接收设备配置]
    B --> C{配置是否为空?}
    C -->|是| D[返回错误: 配置不能为空]
    C -->|否| E[验证心跳间隔]
    E --> F{心跳间隔是否有效?}
    F -->|否| G[返回错误: 心跳间隔无效]
    F -->|是| H[验证最大并发任务数]
    H --> I{任务数是否有效?}
    I -->|否| J[返回错误: 任务数无效]
    I -->|是| K[验证资源限制]
    K --> L{资源限制是否有效?}
    L -->|否| M[返回错误: 资源限制无效]
    L -->|是| N[配置验证通过]
    N --> O[结束]
    
    D --> O
    G --> O
    J --> O
    M --> O
```

## 2. 设备健康检查流程

```mermaid
flowchart TD
    A[开始] --> B[接收设备数据]
    B --> C[计算健康度评分]
    C --> D[确定健康状态]
    D --> E[执行CPU检查]
    E --> F[执行内存检查]
    F --> G[执行磁盘检查]
    G --> H[执行网络检查]
    H --> I[生成告警信息]
    I --> J[返回健康报告]
    J --> K[结束]
    
    D --> D1{健康度评分}
    D1 -->|>=90| D2[excellent]
    D1 -->|>=70| D3[good]
    D1 -->|>=50| D4[fair]
    D1 -->|<50| D5[poor]
    
    D2 --> E
    D3 --> E
    D4 --> E
    D5 --> E
```

## 3. 设备数据处理流程

```mermaid
flowchart TD
    A[开始] --> B[接收原始数据]
    B --> C[验证数据完整性]
    C --> D{验证是否通过?}
    D -->|否| E[返回验证错误]
    D -->|是| F[复制数据到处理结果]
    F --> G[计算健康度评分]
    G --> H[确定设备状态]
    H --> I[添加处理时间戳]
    I --> J[返回处理结果]
    J --> K[结束]
    
    E --> K
    
    C --> C1[检查必需字段]
    C --> C2[验证设备类型]
    C --> C3[验证设备状态]
    C --> C4[验证IP地址]
```

## 4. 告警生成流程

```mermaid
flowchart TD
    A[开始] --> B[接收设备数据和健康度]
    B --> C{健康度<30?}
    C -->|是| D[生成严重告警]
    C -->|否| E{健康度<50?}
    E -->|是| F[生成警告告警]
    E -->|否| G[检查CPU使用率]
    
    G --> H{CPU>95%?}
    H -->|是| I[生成CPU严重告警]
    H -->|否| J{CPU>85%?}
    J -->|是| K[生成CPU警告告警]
    J -->|否| L[检查内存使用率]
    
    L --> M{内存>95%?}
    M -->|是| N[生成内存严重告警]
    M -->|否| O{内存>85%?}
    O -->|是| P[生成内存警告告警]
    O -->|否| Q[检查磁盘使用率]
    
    Q --> R{磁盘>95%?}
    R -->|是| S[生成磁盘严重告警]
    R -->|否| T{磁盘>90%?}
    T -->|是| U[生成磁盘警告告警]
    T -->|否| V[返回告警列表]
    
    D --> V
    F --> V
    I --> V
    K --> V
    N --> V
    P --> V
    S --> V
    U --> V
    
    V --> W[结束]
```

## 5. 设备状态转换流程

```mermaid
flowchart TD
    A[开始] --> B[接收当前状态和目标状态]
    B --> C{当前状态是否有效?}
    C -->|否| D[返回错误: 无效当前状态]
    C -->|是| E[获取允许的状态转换列表]
    E --> F{目标状态是否在允许列表中?}
    F -->|否| G[返回错误: 不允许的状态转换]
    F -->|是| H[状态转换验证通过]
    H --> I[结束]
    
    D --> I
    G --> I
    
    E --> E1[offline -> online/maintenance/deleted]
    E --> E2[online -> offline/busy/maintenance/error]
    E --> E3[busy -> online/offline/error]
    E --> E4[maintenance -> online/offline]
    E --> E5[error -> offline/maintenance]
    E --> E6[deleted -> 无转换]
```

## 6. 设备注册处理流程

```mermaid
flowchart TD
    A[开始] --> B[接收设备注册数据]
    B --> C[验证注册数据]
    C --> D{验证是否通过?}

    L --> M[结束]
    
    E --> M
    
    C --> C1[验证设备名称]
    C --> C2[验证MAC地址]
    C --> C3[验证设备类型]
    C --> C4[验证IP地址]
```

## 7. 设备心跳处理流程

```mermaid
flowchart TD
    A[开始] --> B[接收设备ID和心跳数据]
    B --> C[更新心跳时间]
    C --> D[更新设备状态信息]
    D --> E[重新计算健康度]
    E --> F[自动确定设备状态]
    F --> G[更新最后活跃时间]
    G --> H[记录心跳日志]
    H --> I[返回处理结果]
    I --> J[结束]
    
    F --> F1{检查离线状态}
    F --> F2{检查维护状态}
    F --> F3{根据健康度确定状态}
    
    F1 --> F1A{最后心跳>15分钟?}
    F1A -->|是| F1B[设置为offline]
    F1A -->|否| F2
    
    F2 --> F2A{维护模式?}
    F2A -->|是| F2B[设置为maintenance]
    F2A -->|否| F3
    
    F3 --> F3A{健康度<30?}
    F3A -->|是| F3B[设置为error]
    F3A -->|否| F3C{健康度<70?}
    F3C -->|是| F3D{有运行任务?}
    F3D -->|是| F3E[设置为busy]
    F3D -->|否| F3F[设置为online]
    F3C -->|否| F3G{有运行任务?}
    F3G -->|是| F3E
    F3G -->|否| F3F
```

## 8. 任务分配评分计算流程

```mermaid
flowchart TD
    A[开始] --> B[接收设备数据和任务数据]
    B --> C[计算基础健康度评分]
    C --> D[计算任务负载评分]
    D --> E[计算设备类型匹配度]
    E --> F[计算地理位置因素]
    F --> G[加权计算总分]
    G --> H[返回评分结果]
    H --> I[结束]
    
    C --> C1[健康度 * 40%]
    D --> D1[负载评分 * 30%]
    E --> E1[类型匹配 * 20%]
    F --> F1[地理位置 * 10%]
    
    D1 --> D1A{当前任务数/最大任务数}
    D1A --> D1B[负载评分 = (1-负载比) * 100]
    
    E1 --> E1A{设备类型匹配?}
    E1A -->|是| E1B[100分]
    E1A -->|否| E1C[50分]
    
    F1 --> F1A{地理位置匹配?}
    F1A -->|是| F1B[100分]
    F1A -->|否| F1C[30分]
```

## 总结

以上流程图展示了设备Logic层的主要业务处理流程，包括：

1. **配置管理**：设备配置的验证和生成
2. **健康检查**：综合健康状态评估
3. **数据处理**：设备数据的验证和处理
4. **告警生成**：智能告警系统
5. **状态管理**：设备状态转换验证
6. **注册处理**：设备注册业务逻辑
7. **心跳处理**：设备心跳响应处理
8. **任务分配**：任务分配评分计算

这些流程确保了设备管理的完整性和可靠性，为上层服务提供了强大的业务逻辑支持。
