### 目录/文件职责

* **cmd/onego-server/main.go**

  * 应用入口
  * 加载配置、初始化日志/数据库/缓存/Kafka
  * 启动 Gin HTTP 服务、Prometheus 指标暴露、定时任务

* **configs/**

  * `config.toml`：默认配置
  * `config.development.toml` / `config.production.toml`：环境覆盖
  * 包含 DB、Redis、Kafka、JWT、服务端口 等配置

* **internal/model/**

  * `user.go`、`device.go`、`task.go`：GoFrame gdb 模型定义、表名、字段映射、关联关系

* **internal/service/**

  * `auth.go`：注册、登录、登出、JWT 生成与刷新
  * `user.go`：用户资料查询与更新
  * `device.go`：设备注册、查询、更新、删除
  * `task.go`：任务创建、查询、取消、日志获取

* **internal/router/router.go**

  * 所有路由注册
  * `api/v1` 分组，绑定中间件（`auth`, `cors`, `rate_limit`）
  * 挂载健康检查、指标、业务路由

* **internal/middleware/**

  * `auth.go`：JWT 校验、中止未授权请求
  * `cors.go`：跨域白名单
  * `rate_limit.go`：基于 Redis 的限流

* **internal/handler/**

  * `health.go`：`GET /api/v1/healthz`
  * `metrics.go`：`GET /api/v1/metrics`（Prometheus 格式）

* **internal/job/heartbeat.go**

  * 定时扫描设备心跳状态
  * 离线告警、重试通知

* **pkg/errors/errors.go**

  * 统一业务错误码、错误包装

* **pkg/logger/zap.go**

  * Zap 日志初始化、全局 `Logger` 暴露

* **pkg/cache/redis.go**

  * Redis 客户端初始化、分布式锁封装

* **pkg/kafka/producer.go**

  * Kafka 生产者初始化、消息发送接口

* **pkg/validator/validator.go**

  * 基于 `go-playground/validator` 的请求结构校验封装

* **public/static/**

  * 如需前端静态文件或 Swagger UI

* **scripts/**

  * `build.sh`：编译镜像脚本
  * `migrate.sh`：数据库表结构迁移脚本

* **deployments/docker/Dockerfile**

  * 多阶段构建、体积优化

* **deployments/k8s/**

  * Deployment、Service、ConfigMap、Secret 等

* **test/unit/**

  * 核心服务逻辑单元测试（模拟 DB/Redis/Kafka）

* **test/integration/**

  * API 端到端测试（启动服务、真实 DB 联调）

### 目录/文件职责

* **cmd/onego-client/main.go**

  * 客户端入口
  * 加载配置，初始化日志、缓存
  * 向 `onego-server` 注册、启动心跳与任务监听

* **configs/**

  * 服务端地址、心跳间隔、执行超时、日志级别 等

* **internal/agent/agent.go**

  * 与服务器通讯：注册、心跳、断线重连机制

* **internal/executor/**

  * `shell.go`：本地 Shell 命令执行
  * `container.go`：在容器中执行脚本（支持 Docker/OCI）

* **internal/reporter/report.go**

  * 收集执行结果、日志文件
  * 上报至 Kafka 或 REST 接口

* **internal/middleware/retry.go**

  * 通信与任务执行失败重试策略

* **pkg/logger/zap.go**

  * 客户端日志初始化

* **pkg/cache/local\_cache.go**

  * 本地内存/文件缓存（用于存储短期任务上下文）

* **pkg/utils/system\_info.go**

  * 采集本机 CPU、内存、磁盘、网络等信息

* **public/certs/**

  * 存放 TLS/证书（如需要双向认证）

* **scripts/build.sh**

  * 编译打包脚本

* **scripts/register.sh**

  * 离线环境脚本式注册客户端

* **deployments/docker/Dockerfile**

  * 客户端镜像构建

* **deployments/k8s/daemonset.yaml**

  * 以 DaemonSet 方式在每个节点部署 client

* **deployments/k8s/configmap.yaml**

  * 挂载客户端配置

* **test/unit/executor\_test.go**

  * 模拟命令/容器执行单元测试

* **test/integration/agent\_integration\_test.go**

  * 与假服务器联调（模拟注册、心跳、上报）
