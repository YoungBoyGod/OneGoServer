# 多环境配置使用指南

## 📋 概述

本指南详细说明如何在 learngo0619 项目中使用多环境配置，支持开发(dev)、生产(prod)、测试(test)三套环境。

## 📁 配置文件结构

```
config/
├── server.yaml          # 默认配置
├── server.dev.yaml      # 开发环境配置
├── server.prod.yaml     # 生产环境配置
└── server.test.yaml     # 测试环境配置
```

### 各环境配置对比

| 环境 | 主机地址 | 端口 | 模式 | 应用名称 |
|------|----------|------|------|----------|
| **开发环境** | 127.0.0.1 | 8080 | debug | learngo0619-dev |
| **生产环境** | 0.0.0.0 | 80 | release | learngo0619 |
| **测试环境** | 127.0.0.1 | 9999 | test | learngo0619-test |

## 🚀 使用方法

### 1. CLI参数方式（推荐）

```bash
# 启动开发环境
./learngo0619 server --env dev --verbose

# 启动生产环境
./learngo0619 server --env prod --verbose

# 启动测试环境
./learngo0619 server --env test --verbose

# 使用自定义配置文件
./learngo0619 server --config config/custom.yaml
```

### 2. 环境变量方式

```bash
# 设置环境变量后启动
export APP_ENV=dev
./learngo0619 server --verbose

# 或者一行命令
APP_ENV=prod ./learngo0619 server --verbose
```

### 3. Makefile快捷命令

```bash
# 环境启动命令
make server-dev    # 启动开发环境
make server-prod   # 启动生产环境  
make server-test   # 启动测试环境

# 环境变量方式
make dev-env       # APP_ENV=dev 启动
make prod-env      # APP_ENV=prod 启动
make test-env      # APP_ENV=test 启动

# 快速启动
make quick-dev     # 安装依赖+编译+启动开发环境
make quick-prod    # 安装依赖+编译+启动生产环境
```

## 🔧 配置优先级

配置加载的优先级（从高到低）：

1. **CLI参数覆盖** (`--port`, `--host`)
2. **环境变量覆盖** (`SERVER_PORT`, `SERVER_HOST` 等)
3. **指定配置文件** (`--config`)
4. **环境参数** (`--env dev|prod|test`)
5. **环境变量** (`APP_ENV=dev|prod|test`)
6. **默认配置** (server.dev.yaml)

### 示例：优先级演示

```bash
# 最终端口为 9000 (CLI参数优先级最高)
APP_ENV=prod SERVER_PORT=8888 ./learngo0619 server --env dev --port 9000
```

## 🛠️ 环境变量覆盖

支持以下环境变量覆盖配置：

```bash
# 服务器配置
export SERVER_HOST="0.0.0.0"      # 覆盖主机地址
export SERVER_PORT="3000"         # 覆盖端口
export SERVER_MODE="release"      # 覆盖服务器模式

# 应用配置  
export APP_NAME="my-custom-app"    # 覆盖应用名称
export APP_VERSION="2.0.0"        # 覆盖应用版本

# 环境设置
export APP_ENV="prod"              # 设置环境
```

## 📦 编译时环境配置

### 单环境编译

```bash
# 编译开发版本
make build-dev      # 生成 learngo0619-dev

# 编译生产版本  
make build-prod     # 生成 learngo0619-prod

# 编译测试版本
make build-test     # 生成 learngo0619-test
```

### 多平台编译

```bash
# 编译所有平台的发布版本
make build-release-all

# 生成的文件:
# bin/learngo0619-dev-linux-amd64
# bin/learngo0619-dev-darwin-amd64  
# bin/learngo0619-prod-linux-amd64
# bin/learngo0619-prod-darwin-amd64
```

## 🐳 Docker 部署示例

### Dockerfile

```dockerfile
FROM golang:1.21-alpine AS builder
WORKDIR /app
COPY . .
RUN make build-prod

FROM alpine:latest
RUN apk --no-cache add ca-certificates
WORKDIR /root/
COPY --from=builder /app/learngo0619-prod .
COPY --from=builder /app/config ./config
CMD ["./learngo0619-prod", "server", "--env", "prod"]
```

### docker-compose.yml

```yaml
version: '3.8'
services:
  app-dev:
    build: .
    environment:
      - APP_ENV=dev
      - SERVER_PORT=8080
    ports:
      - "8080:8080"
    command: ["./learngo0619-dev", "server", "--env", "dev", "--verbose"]
  
  app-prod:
    build: .
    environment:
      - APP_ENV=prod
      - SERVER_PORT=80
    ports:
      - "80:80"
    command: ["./learngo0619-prod", "server", "--env", "prod"]
```

## 🎯 最佳实践

### 1. 开发阶段

```bash
# 使用热重载开发
make dev

# 或者指定开发环境
make server-dev
```

### 2. 测试阶段

```bash
# 启动测试环境
make server-test

# 验证配置
make config-validate-test
```

### 3. 部署阶段

```bash
# 编译生产版本
make build-prod

# 验证生产配置
make config-validate-prod

# 启动生产环境
make server-prod
```

## 🚨 注意事项

1. **生产环境安全**: 生产环境下确保配置文件权限正确
2. **端口冲突**: 不同环境使用不同端口避免冲突
3. **环境变量**: 容器部署时优先使用环境变量配置
4. **配置验证**: 部署前务必验证配置文件的正确性
5. **日志级别**: 生产环境建议使用 `release` 模式
