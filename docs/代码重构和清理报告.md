## 🎯 Cobra vs Air 功能对比

### Cobra CLI 框架
| 特性 | 功能 | 使用场景 |
|------|------|----------|
| 🎮 **命令管理** | 提供子命令结构 | `./app server`, `./app config` |
| 📋 **参数处理** | 标志和参数解析 | `--port 8080`, `--verbose` |
| 💬 **帮助系统** | 自动生成帮助文档 | `./app --help` |
| 🏗️ **架构组织** | 模块化命令结构 | `cmd/server.go`, `cmd/config.go` |

### Air 热重载工具
| 特性 | 功能 | 使用场景 |
|------|------|----------|
| 👀 **文件监控** | 实时监控代码变化 | 保存文件自动重启 |
| 🔄 **自动编译** | 检测变化后重新编译 | 开发时免手动重启 |
| 🚀 **进程管理** | 优雅重启应用进程 | 热重载开发模式 |
| ⚙️ **配置灵活** | 可配置监控规则 | `.air.toml` 配置文件 |

### 协作关系 🤝

```
Air 监控文件变化 → 自动重新编译 → 运行 Cobra 程序
     ↓               ↓              ↓
  cmd/*.go        go build       ./app server
  server/*.go   重新编译        启动HTTP服务
  *.yaml        Air重启        优雅关闭/重启
```

**结论**：Cobra 和 Air **不重叠**，而是**完美互补**：
- Cobra 负责程序的**命令行界面**
- Air 负责开发时的**自动化工作流**
