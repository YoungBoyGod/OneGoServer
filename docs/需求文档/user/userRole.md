# 用户角色管理需求文档

## 1. 功能描述
用户角色管理用于为用户分配、查询、变更其在系统中的角色。

## 2. 目标
- 支持管理员为用户分配和变更角色。
- 支持查询用户角色列表。

## 3. 输入输出
### 输入
- 用户ID
- 角色列表

### 输出
- 操作结果（成功/失败）
- 用户角色详情

## 4. API/接口设计
| 接口 | 方法 | 路径 | 描述 |
| ---- | ---- | ---- | ---- |
| 查询用户角色 | GET | /api/user/v1/role/{userId} | 查询指定用户角色 |
| 分配/变更角色 | POST | /api/user/v1/role/{userId} | 分配或变更用户角色 |

#### 请求示例
GET /api/user/v1/role/123
POST /api/user/v1/role/123
```json
{
  "roles": ["admin", "user"]
}
```

#### 响应示例
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "userId": 123,
    "roles": ["admin", "user"]
  }
}
```

## 5. 数据结构
```go
UserRoleRequest struct {
    Roles []string `json:"roles"`
}
UserRoleResponse struct {
    UserID int64    `json:"userId"`
    Roles  []string `json:"roles"`
}
```

## 6. 异常处理
- 用户不存在：返回404，"用户不存在"
- 权限不足：返回403，"无权限"
- 参数校验失败：返回400，"参数错误"
- 服务器异常：返回500，"服务器错误"

## 7. 流程图
```mermaid
flowchart TD
    A[开始] --> B[校验用户ID]
    B -- 合法 --> C[权限校验]
    C -- 通过 --> D[查询/变更角色]
    D -- 成功 --> E[返回角色详情]
    D -- 失败 --> F[返回500]
    C -- 不通过 --> G[返回403]
    B -- 非法 --> H[返回404]
```

## 8. 安全性
- 仅允许有权限的管理员操作。
- 输入参数严格校验。

## 9. 日志
- 记录角色分配、变更操作。
- 记录异常和失败原因。

## 10. 测试用例
1. 查询用户角色。
2. 分配/变更角色成功。
3. 用户不存在，返回404。
4. 权限不足，返回403。
5. 参数非法，返回400。
6. 服务器异常，返回500。
