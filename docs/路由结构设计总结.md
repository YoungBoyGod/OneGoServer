## 🏗️ 路由设计原则

### 1. RESTful API规范
- **资源命名**: 使用复数名词 (users, devices, tasks, alerts)
- **HTTP方法**: 
  - GET (查询)
  - POST (创建) 
  - PUT (更新)
  - DELETE (删除)
- **路径参数**: 使用 `:id` 表示资源标识符
- **查询参数**: 用于过滤、分页、排序

### 2. 路由分组管理
```go
// 按业务模块分组
auth := v1.Group("/auth")        // 认证相关
users := v1.Group("/users")      // 用户管理
devices := v1.Group("/devices")  // 设备管理  
tasks := v1.Group("/tasks")      // 任务管理
alerts := v1.Group("/alerts")    // 告警系统
```

### 3. 统一响应格式
```go
// 通用响应结构
type CommonRes struct {
    Code    int         `json:"code"`
    Message string      `json:"message"`
    Data    interface{} `json:"data"`
}

// 分页响应结构
type PageRes struct {
    CommonRes
    Page     int `json:"page"`
    PageSize int `json:"page_size"`
    Total    int `json:"total"`
}
```

## 🔧 技术实现细节

### 1. 路由注册方式
- 使用Gin框架的路由组功能
- 支持中间件链式调用
- 占位符处理器避免编译错误

### 2. 参数类型支持
- **Path参数**: `:id` 资源标识符
- **Query参数**: `?page=1&page_size=10` 查询条件
- **Body参数**: JSON格式请求体
- **Header参数**: 认证令牌等

### 3. 错误处理策略

```go
    })
}
```
